# Duelo de Naves — frontend

Frontend en React + TypeScript (Vite) del juego **Duelo de Naves**. Ver instrucciones de
instalación, ejecución y despliegue completas en el [README del proyecto](../README.md).

## Estructura

```
src/
├── App.tsx          # pantalla de inicio y cambio a la pantalla de juego
├── DueloNaves.tsx    # estado de la partida, fases del turno, llamadas fetch a la API
├── Escena.tsx        # naves, barras de vida/energía y animación del proyectil
├── App.css            # estilos de la pantalla de inicio
├── DueloNaves.css      # estilos de la escena de juego
└── index.css           # variables de color y estilos base
```
